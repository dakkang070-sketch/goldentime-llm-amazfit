## ✅ 완전한 Google AI Studio 프롬프트

"React Native + Expo로 Starmax 스마트워치 전용 건강 모니터링 앱을 만들어주세요.

핵심 요구사항:
1. **회원가입/로그인 플로우** - 이메일, 소셜 로그인, 생체인증
2. **블루투스 기기 연동** - Starmax 스마트워치 검색, 연결, 동기화  
3. **실시간 데이터 모니터링** - 10종 생체 데이터 (심박수, 혈압, 산소포화도, 체온, 혈당, 걸음수, 수면, 스트레스, 호흡수, HRV)
4. **응급 상황 감지** - 자동 이상 징후 감지 및 알림
5. **프리미엄 다크 테마** - 글래스 모피즘 효과, 부드러운 애니메이션
6. **건강 점수 시스템** - AI 기반 종합 건강 점수 계산
7. **데이터 시각화** - 실시간 차트, 트렌드 분석, 리포트 생성

전체 화면 구성:
- 스플래시/온보딩 (3단계)
- 회원가입 (이메일, 휴대폰, 소셜)  
- 로그인 (이메일, 생체인증)
- 블루투스 기기 연결 (검색 → 페어링 → 동기화)
- 메인 대시보드 (10종 데이터 실시간 표시)
- 응급 상황 알림 (자동 감지 → 알림 → 조치)
- 설정/프로필 (개인정보, 기기 관리, 알림 설정)

모든 컴포넌트는 재사용 가능하게 만들고, React Native best practice를 따르세요."
