# 관제화면 표시 문제 해결 계획

## 문제 상황
사용자가 "관제화면이 안나와"라고 하여, 현재 시스템의 관제화면 표시 상태를 점검하고 접근 방법을 확인하겠습니다.

## 시스템 상태 확인
1. **관제화면 컴포넌트 구조 확인**:
   - `CrimeDashboard.tsx` - 3열 레이아웃(목록/지도/상세) 구현됨
   - `CrimeList.tsx` - 사례 목록 표시 컴포넌트
   - `CrimeCaseCard` - 개별 사례 카드 컴포넌트

2. **네비게이션 확인**:
   - App.tsx에 "범죄 관제" 메뉴가 사이드바에 구현됨
   - `activeTab === "crime"`일 때 `CrimeDashboard` 렌더링

3. **데이터 흐름 확인**:
   - 소켓 연결로 실시간 업데이트 확인됨
   - API 엔드포인트 `/api/school-violence/cases`로 데이터 조회
   - 응급 키워드 우선순위 로직 작동 확인

## 해결 방안
1. **브라우저 콘솔 확인**: 개발자 도구(F12)에서 오류 메시지 확인
2. **네트워크 탭 확인**: API 호출 상태 및 응답 확인
3. **소켓 연결 확인**: 실시간 통신 상태 점검
4. **직접 접근 테스트**: 브라우저에서 `http://localhost:3002` 접속 후 "범죄 관제" 메뉴 클릭

현재 코드상으로는 관제화면이 정상적으로 표시되어야 합니다. 실제 접속하여 확인해보겠습니다.
