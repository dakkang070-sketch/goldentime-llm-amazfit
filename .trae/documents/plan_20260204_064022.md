## 문제 분석
응급관제 지도(WorkingMap)에서 경로가 직선으로 표시되는 문제를 확인했습니다. 현재 구현은 OSRM API가 실패하면 단순 직선 경로로 대체되고 있습니다.

## 개선 계획

### 1. OSRM 서버 이중화
- [WorkingMap.tsx](file:///Users/jace/Documents/llm/goldentime-llm/frontend/components/WorkingMap.tsx#L547-L572)의 fetchPath 함수 개선
- 주 서버(`routing.openstreetmap.de`)와 백업 서버를 순차적으로 시도
- 각 서버별 타임아웃 8초 설정

### 2. Manhattan 경로 대체 로직
- 직선 경로 대신 도로와 유사한 'ㄴ'자 형태의 경로 생성
- 수평-수직 이동을 번갈아 사용하여 자연스러운 경로 표현

### 3. 에러 처리 강화
- 네트워크 오류 시에도 시스템이 멈추지 않도록 처리
- 로깅 개선으로 디버깅 용이성 향상

### 4. 경로 시각화 개선
- 기존 파란색/빨간색 점선 유지
- 애니메이션 효과 유지

이러한 개선을 통해 응급차량이 환자에게 가는 경로가 실제 도로를 따라 표시되며, 응급차량의 이동 상황을 더 정확하게 시각화할 수 있습니다.
