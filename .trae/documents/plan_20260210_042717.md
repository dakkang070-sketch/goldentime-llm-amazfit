## 🚨 응급 사용자앱 전용 DB 연동 계획

### ✅ 현재 확인사항
- **응급관제 전용 백엔드**: 범죄관제와는 완전히 분리됨
- **MongoDB 구축됨**: 사용자, 생체 데이터, 응급 상황 모델 존재
- **응급 상황 처리 시스템**: 자동 매칭, 병원 연동, 구조대 배정 완료

### 🔧 응급 사용자앱용 필수 수정사항

#### 1단계: 사용자 모델 응급앱 전용 확장 (15분)
- **STARMAX 기기 정보 필드 추가**:
  ```javascript
  starmaxDevice: {
    deviceId: String,      // STARMAX BLE 기기 ID
    deviceName: String,      // STARMAX WATCH ULTRA G1
    deviceType: String,      // watch/band
    connectedAt: Date,       // 연결 시각
    lastSyncAt: Date,        // 마지막 동기화
    connectionStatus: String // connected/disconnected
  }
  ```
- **응급앱 사용자 플래그 추가**:
  ```javascript
  isEmergencyAppUser: { type: Boolean, default: true }
  ```

#### 2단계: 응급 사용자앱 전용 API 생성 (30분)
- **POST /api/mobile/signup**: 응급 사용자 회원가입
- **POST /api/mobile/login**: 응급 사용자 로그인
- **POST /api/mobile/biometric**: STARMAX 실시간 데이터 저장
- **POST /api/mobile/emergency**: 응급 상황 자동 신고
- **GET /api/mobile/profile**: 사용자 프로필 조회
- **PUT /api/mobile/profile**: 프로필 수정

#### 3단계: STARMAX BLE 데이터 통합 (20분)
- **실시간 데이터 파싱 서비스**:
  - STARMAX 기기 데이터 → DB 저장 형식 변환
  - 데이터 유효성 검증 (이상치 필터링)
  - 자동 응급 상황 감지 (AI 분석)
- **응급 상황 자동 생성**:
  - 위험도 4~5단계 자동 응급 케이스 생성
  - 자동 병원 매칭 및 구조대 배정
  - 실시간 위치 추적 데이터 저장

#### 4단계: 실시간 모니터링 시스템 (15분)
- **WebSocket 연결**: 실시간 데이터 스트리밍
- **자동 분석 엔진**: 30초마다 데이터 분석
- **푸시 알림 시스템**: 응급 상황 시 자동 알림

#### 5단계: 보안 및 성능 최적화 (10분)
- **JWT 인증**: 모바일 앱 전용 토큰 발급
- **데이터 암호화**: 민감한 건강 정보 보호
- **캐싱 전략**: Redis 활용 빠른 데이터 접근
- **배치 처리**: 대용량 데이터 효율적 처리

### 📱 모바일 앱 연동 포인트
1. **회원가입 시**: 자동으로 응급관제 시스템에 등록
2. **기기 연결 시**: STARMAX BLE 데이터 자동 수집 시작
3. **응급 감지 시**: 자동으로 응급 케이스 생성 및 매칭
4. **위치 추적**: 실시간 위치 정보 저장 및 공유
5. **데이터 동기화**: 주기적 데이터 백업 및 동기화

### 🎯 핵심 차이점
- **범죄관제 X**: 오직 응급의료 상황만 처리
- **자동화 시스템**: AI가 응급 상황 자동 판단 및 처리
- **실시간 연동**: STARMAX 기기와 즉시 동기화
- **전문가 매칭**: 응급구조사, 병원 자동 배정
