## 문제 분석
현재 왼쪽 패널에서 회원을 클릭하면 지도에 회원 위치가 표시되고 말풍선이 나타나지만, 말풍선이 계속 유지되는 문제가 있습니다.

## 개선 사항

### 1. 말풍선 닫기 기능 추가
- [CrimeMap.tsx](file:///Users/jace/Documents/llm/goldentime-llm/frontend/components/CrimeMap.tsx)의 팝업에 닫기 버튼 추가
- 지도 빈 공간 클릭 시 선택 해제 및 말풍선 닫기 기능 개선
- 다른 회원 선택 시 이전 말풍선 자동 닫기

### 2. 마우스 호버 동작 개선  
- 마우스 호버 시 잠시 보여주고, 클릭 시에만 계속 유지되도록 변경
- 선택된 회원의 말풍선도 필요시 닫을 수 있도록 개선

### 3. UI/UX 개선
- 말풍선 스타일에 닫기 버튼 추가
- 더 직관적인 상호작용 제공

이러한 개선을 통해 사용자가 말풍선을 필요에 따라 쉽게 닫을 수 있고, 더 나은 지도 상호작용 경험을 제공할 수 있습니다.
