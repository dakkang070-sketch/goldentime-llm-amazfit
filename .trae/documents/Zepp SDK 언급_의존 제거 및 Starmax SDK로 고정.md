## 요구사항 정리
- Zepp SDK/Zepp API는 사용하지 않으며, 앞으로는 **Starmax SDK만 사용**
- 코드/로그/문서/환경변수 체크 등에서 Zepp 관련 내용이 나오지 않게 정리
- 이후 작업/답변에서도 Zepp를 전제로 안내하지 않기

## 즉시 반영할 작업(코드 변경)
- 코드베이스 전체에서 `ZEPP`, `Zepp`, `zepp` 키워드 검색
- 백엔드 시작 로그에서 `ZEPP_CLIENT_ID/SECRET` 미설정 경고 출력 제거(또는 Starmax로 대체)
- 사용하지 않는 Zepp 관련 서비스/모듈/라우트/설정이 있으면 제거 또는 비활성화
- 문서(.md), .env.example, README 등에 남아있는 Zepp 안내 제거

## Starmax 기준으로 정리
- Starmax 연동 entrypoint/서비스를 확인하고, 관련 설정/로그/에러 메시지를 Starmax 기준으로 통일
- Zepp 관련 코드가 Starmax 흐름에 영향을 주는지(조건문, fallback, feature flag) 확인 후 정리

## 검증
- 백엔드 재시작 시 Zepp 경고 로그가 더 이상 출력되지 않는지 확인
- 응급사용자앱/백엔드에서 Starmax 관련 기능이 정상 동작하는지(빌드/런타임) 확인

## 대화/기억 반영
- 제 응답/작업 기준을 **“Zepp 미사용, Starmax만 사용”**으로 고정하도록 내부 기억(선호/규칙)을 업데이트
