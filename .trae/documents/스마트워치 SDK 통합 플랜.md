## 🎯 React Native 사용자용 응급관제 앱 제작 계획

### 1단계: React Native 프로젝트 초기화 (15분)
- 새로운 React Native 프로젝트 생성
- TypeScript 설정
- 필요한 패키지 설치 (네비게이션, BLE, 차트 등)

### 2단계: 기본 구조 설정 (20분)
- App.tsx 메인 컴포넌트
- 네비게이션 구조 (탭 네비게이션)
- 기본 스크린 컴포넌트들

### 3단계: Starmax BLE 통합 (30분)
- Starmax BLE SDK 연동
- 실시간 생체 데이터 수집
- 데이터 파싱 및 상태 관리

### 4단계: UI/UX 구현 (Google AI Studio 디자인) (30분)
- 프리미엄 글래스모피즘 디자인
- 실시간 대시보드
- 건강 점수 시각화
- 응급 호출 버튼

### 5단계: LLM 연동 (20분)
- 실시간 데이터 분석
- 건강 리포트 생성
- 응급 상황 판단

### 6단계: 4단계 응급 연락망 (20분)
- 응급 상황 감지
- 자동 에스컬레이션
- 푸시 알림

### 7단계: Android 빌드 및 설치 (15분)
- APK 생성
- Android 기기 설치
- 테스트
