# 🤖 완전 자동 학습 시스템 가이드

골든타임 LLM의 완전 자동 학습 시스템은 실시간으로 수집된 응급상황 데이터를 바탕으로 AI 모델을 자동으로 재훈련하고 배포하는 시스템입니다.

## 🚀 시스템 개요

### **기본 구조**
```
실시간 데이터 수집 → 자동 전처리 → 모델 재훈련 → 성능 검증 → 자동 배포/롤백
```

### **주요 기능**
- ✅ **실시간 데이터 수집**: 응급상황 발생 시마다 자동 학습 데이터 수집
- ✅ **배치 학습**: 매일 정해진 시간에 대량 데이터 기반 재훈련
- ✅ **증분 학습**: 50개 이상 새 데이터 누적 시 실시간 재훈련
- ✅ **성능 검증**: 자동 테스트를 통한 모델 품질 검증
- ✅ **자동 배포**: 성능 기준 통과 시 자동 프로덕션 배포
- ✅ **안전 롤백**: 성능 저하 시 이전 모델로 자동 복원
- ✅ **모델 백업**: 최대 5개 이전 버전 자동 보관

## ⚙️ 시작하기

### **1. 환경변수 설정**
`.env` 파일에 다음 설정 추가:
```bash
# 완전 자동 학습 시스템 활성화
ENABLE_AUTO_LEARNING=true

# 자동 배포 활성화 (주의: 프로덕션에서는 신중히 설정)
ENABLE_AUTO_DEPLOY=false

# 기본 Ollama 설정
ENABLE_OLLAMA=true
USE_FINETUNED_MODEL=true
OLLAMA_FINETUNED_MODEL=goldentime-emergency:latest
```

### **2. 서버 시작**
```bash
npm start
```

시작 로그에서 다음 메시지 확인:
```
🤖 완전 자동 학습 시스템 활성화됨
📅 배치 학습 스케줄: 0 2 * * *
📊 실시간 학습 임계치: 50개
```

## 📊 학습 시나리오

### **배치 학습 (매일 새벽 2시)**
```javascript
// 자동 실행 조건
- 새로운 학습 데이터 50개 이상
- 이전 배치 학습 이후 새 응급상황 발생
- 시스템 안정성 확인 완료

// 실행 단계
1. 데이터 수집 및 품질 검증
2. 현재 모델 백업
3. 새 모델 훈련 (약 5-10분)
4. 성능 테스트 (80% 정확도 기준)
5. 자동 배포 또는 롤백
```

### **증분 학습 (5분마다 확인)**
```javascript
// 트리거 조건
- 새로운 응급상황 데이터 50개 누적
- 현재 훈련 중이지 않은 상태
- 마지막 학습 이후 1시간 경과

// 경량화된 재훈련
- 기존 모델 + 새 데이터 결합
- 빠른 훈련 (약 2-5분)
- 실시간 성능 검증
```

## 🛠️ API 관리 인터페이스

### **학습 상태 조회**
```bash
GET /api/auto-learning/status
Authorization: Bearer <admin_token>
```

**응답 예시:**
```json
{
  "success": true,
  "data": {
    "isTraining": false,
    "lastTrainingTime": "2026-01-15T02:00:00.000Z",
    "totalTrainingRuns": 25,
    "averageAccuracy": 0.87,
    "recentHistory": [
      {
        "timestamp": "2026-01-15T02:00:00.000Z",
        "dataCount": 127,
        "accuracy": 0.89,
        "deployed": true
      }
    ]
  }
}
```

### **수동 배치 학습 트리거**
```bash
POST /api/auto-learning/trigger-batch
Authorization: Bearer <admin_token>
```

### **수동 증분 학습 트리거**
```bash
POST /api/auto-learning/trigger-incremental
Authorization: Bearer <admin_token>
```

### **새 데이터 개수 확인**
```bash
GET /api/auto-learning/data-count
```

**응답 예시:**
```json
{
  "success": true,
  "data": {
    "newDataCount": 73,
    "threshold": 50,
    "readyForTraining": true
  }
}
```

### **모델 롤백**
```bash
POST /api/auto-learning/rollback
Authorization: Bearer <admin_token>
```

## 🎯 고급 설정

### **설정 파라미터**
```javascript
const AUTO_LEARNING_CONFIG = {
  MIN_NEW_DATA_THRESHOLD: 50,      // 최소 50개 새 데이터
  MAX_DATA_THRESHOLD: 1000,        // 최대 1000개로 제한
  CRON_SCHEDULE: '0 2 * * *',      // 매일 새벽 2시
  MIN_ACCURACY_THRESHOLD: 0.8,     // 최소 80% 정확도
  MAX_MODEL_BACKUPS: 5,            // 최대 5개 백업
  ENABLE_AUTO_DEPLOY: false,       // 자동 배포 비활성화
  ENABLE_ROLLBACK: true            // 자동 롤백 활성화
};
```

### **커스텀 스케줄링**
```bash
# 매 6시간마다 배치 학습
CRON_SCHEDULE="0 */6 * * *"

# 매주 일요일 새벽 3시
CRON_SCHEDULE="0 3 * * 0"

# 매일 오전 9시와 오후 9시
```
