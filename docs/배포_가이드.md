# 골든타임 LLM 배포 가이드

## 🚀 배포 방법

### 방법 1: Docker Compose (권장)

```bash
# 1. 환경변수 설정
cp config/env.example .env
# .env 파일 편집

# 2. 배포 스크립트 실행
chmod +x scripts/deploy.sh
./scripts/deploy.sh

# 또는 수동 실행
docker-compose build
docker-compose up -d
```

### 방법 2: 수동 배포

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정
cp config/env.example .env
# .env 파일 편집

# 3. MongoDB 실행
mongod

# 4. 서버 실행
npm start
```

## 📦 Docker 서비스

### 서비스 목록

- **mongodb**: MongoDB 데이터베이스
- **backend**: Node.js 백엔드 서버
- **frontend**: React 프론트엔드 (Nginx)

### 포트

- 백엔드: `3000`
- 프론트엔드: `5173`
- MongoDB: `27017`

### 명령어

```bash
# 서비스 시작
docker-compose up -d

# 서비스 중지
docker-compose down

# 로그 확인
docker-compose logs -f

# 특정 서비스 로그
docker-compose logs -f backend

# 서비스 재시작
docker-compose restart backend

# 컨테이너 상태 확인
docker-compose ps
```

## 🔧 환경변수 설정

`.env` 파일에 다음 변수들을 설정하세요:

```env
# 필수
MONGODB_URI=mongodb://mongodb:27017/goldentime
JWT_SECRET=your-secret-key-here

# 선택사항
NODE_ENV=production
PORT=3000
OLLAMA_BASE_URL=http://localhost:11434
ENABLE_OLLAMA=true
FRONTEND_URL=http://localhost:5173
```

## 📈 성능 최적화

### MongoDB 인덱스

프로덕션 환경에서는 다음 인덱스들이 자동 생성됩니다:

- `users`: email, phone (unique)
- `biometric_data`: userId + collectedAt
- `emergency_cases`: status + emergencyLevel
- `paramedics`: status + currentLocation

### 캐싱

- 인메모리 캐시 사용 중
- 프로덕션에서는 Redis 사용 권장

## 🐛 문제 해결

### MongoDB 연결 실패

```bash
# MongoDB 컨테이너 확인
docker-compose ps mongodb

# MongoDB 로그 확인
docker-compose logs mongodb

# MongoDB 재시작
docker-compose restart mongodb
```

### 백엔드 서버 오류

```bash
# 로그 확인
docker-compose logs backend

# 환경변수 확인
docker-compose exec backend env

# 컨테이너 재시작
docker-compose restart backend
```

### 포트 충돌

```bash
# 포트 사용 확인
lsof -i :3000
lsof -i :5173
lsof -i :27017

# docker-compose.yml에서 포트 변경
```
