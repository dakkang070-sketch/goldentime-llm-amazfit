# 골든타임 LLM 파인튜닝 가이드

## 개요

골든타임 LLM 시스템은 Ollama를 사용하여 의료 응급 상황 분석에 특화된 커스텀 모델을 생성할 수 있습니다.

## 파인튜닝 방식

현재 시스템은 **Ollama Modelfile**을 사용한 프롬프트 엔지니어링 방식으로 구현되어 있습니다. 이는 실제 모델 가중치를 변경하는 파인튜닝보다는 시스템 프롬프트와 템플릿을 최적화하는 방식입니다.

## 파일 구조

```
backend/
├── data/
│   ├── fine-tuning-dataset.json          # 기본 학습 데이터셋
│   └── Modelfile                          # Ollama 모델 설정 파일
scripts/
├── fine-tune-model.sh                    # 모델 생성 스크립트
└── prepare-fine-tuning-data.js           # 학습 데이터 준비 스크립트
backend/services/
└── fineTuningService.js                  # 학습 데이터 수집 서비스
```

## 사용 방법

### 1. 기본 모델 확인

```bash
ollama list
```

### 2. 커스텀 모델 생성

```bash
cd /path/to/goldentime-llm
chmod +x scripts/fine-tune-model.sh
./scripts/fine-tune-model.sh
```

이 스크립트는:
- Ollama 설치 확인
- 기본 모델(llama3.1:8b) 확인/다운로드
- Modelfile을 사용하여 `goldentime-emergency:latest` 모델 생성

### 3. 환경변수 설정

`.env` 파일에 다음 설정 추가:

```env
# 파인튜닝된 모델 사용
USE_FINETUNED_MODEL=true
OLLAMA_FINETUNED_MODEL=goldentime-emergency:latest
ENABLE_OLLAMA=true
```

### 4. 모델 테스트

```bash
ollama run goldentime-emergency:latest "기초선 심박수: 70 bpm, 현재 심박수: 45 bpm, 스트레스: 85"
```

## 학습 데이터 준비

### 자동 수집

시스템은 응급 상황 발생 시 자동으로 학습 데이터를 수집합니다. `fineTuningService.js`가 이를 처리합니다.

### 수동 수집

과거 데이터를 기반으로 학습 데이터셋 생성:

```bash
node scripts/prepare-fine-tuning-data.js
```

이 스크립트는:
- MongoDB에서 응급도 3 이상의 케이스 조회
- 생체 데이터와 분석 결과를 매칭
- `fine-tuning-dataset-combined.json` 파일 생성

## Modelfile 커스터마이징

`backend/data/Modelfile` 파일을 수정하여 모델 동작을 조정할 수 있습니다:

- **SYSTEM**: 시스템 프롬프트 (모델의 역할과 규칙 정의)
- **PARAMETER**: 모델 파라미터 (temperature, top_p 등)
- **TEMPLATE**: 입력 템플릿 형식

## 학습 데이터 품질 관리

시스템은 자동으로 학습 데이터의 품질을 검증합니다:

- 필수 필드 확인
- 텍스트 길이 검증 (20~500자)
- 의료 진단 표현 검사 (진단, 질병, 확정 등 금지)

## 향후 개선 사항

### 실제 파인튜닝 (LoRA)

현재는 프롬프트 엔지니어링만 사용하지만, 향후 실제 파인튜닝을 위해:

1. **LoRA (Low-Rank Adaptation)** 방식 구현
2. **데이터셋 확장** (더 많은 응급 상황 케이스)
3. **평가 지표** 정의 및 모델 성능 측정
4. **A/B 테스트** (기본 모델 vs 파인튜닝 모델)

### 데이터셋 확장

- 실제 운영 데이터 수집
- 의료진 피드백 반영
- 다양한 응급 상황 케이스 추가

## 주의사항

1. **의료 진단 금지**: 모델은 항상 "가능성", "의심", "권고" 표현만 사용
2. **데이터 프라이버시**: 학습 데이터에는 개인정보가 포함되지 않도록 주의
3. **정기적 업데이트**: 새로운 데이터로 모델을 주기적으로 재생성 권장
