# 🏷️ 정교한 의료 데이터 라벨링 시스템

골든타임 LLM의 정교한 의료 데이터 라벨링 시스템은 AI 모델의 정확성과 안전성을 보장하는 핵심 구성요소입니다.

## 🎯 시스템 개요

### **기존 vs 개선된 라벨링**
```
기존 (단순)          ➔   개선된 (정교한)
─────────────────────────────────────────────
응급도: 1-5              ➔   8단계 정밀 라벨링
이상징후: 6가지          ➔   50+ 세분화 라벨
검증: 없음              ➔   의료진 검증 시스템
품질관리: 기본           ➔   AI 신뢰도 + 정확도
```

### **8단계 다중 라벨링 구조**
1. **🫀 생체신호 라벨링** - 심박수, 스트레스, 패턴 분석
2. **🏃 활동 라벨링** - 움직임, 낙상위험, 이동능력
3. **🚨 응급분류** - 주요/세부 카테고리, 트리아지 레벨
4. **⏱️ 시간패턴** - 발병속도, 진행추세, 지속시간
5. **⚠️ 위험평가** - 사망, 입원, 악화 위험도
6. **🚑 대응우선순위** - 긴급도, 자원수준, 병원등급
7. **✅ 품질관리** - 정확도, 의료진검증, AI신뢰도
8. **📋 메타데이터** - 태그, 출처, 버전관리

## 📊 라벨링 상세 분류

### **1단계: 생체신호 라벨링**
```javascript
vitalSignLabels: {
  heartRateAbnormality: [
    'normal',              // 정상 (60-100)
    'bradycardia',         // 서맥 (<60)
    'tachycardia',         // 빈맥 (>100)  
    'severe_bradycardia',  // 심각한 서맥 (<40)
    'severe_tachycardia',  // 심각한 빈맥 (>150)
    'arrhythmia_suspected' // 부정맥 의심
  ],
  heartRatePattern: [
    'stable',              // 안정적
    'gradual_increase',    // 점진적 증가
    'sudden_spike',        // 급격한 상승
    'sudden_drop'          // 급격한 하락
  ],
  stressLevel: ['low', 'moderate', 'high', 'severe', 'crisis']
}
```

### **2단계: 응급분류 라벨링**
```javascript
emergencyClassification: {
  primaryCategory: [
    'cardiac_event',        // 심장 관련
    'respiratory_distress', // 호흡 곤란

    'metabolic_crisis',     // 대사 위기
    // ... 10개 주요 카테고리
  ],

    'level_1_resuscitation', // 소생술 필요

    'level_5_non_urgent'     // 비긴급 (120분 이내)
  ]
}
```

## 🔄 자동 라벨링 프로세스

### **실시간 자동 라벨링**
```
응급상황 발생 → 생체데이터 수집 → 자동 라벨링 생성 → 품질 검증 → 데이터베이스 저장
     ↓              ↓              ↓              ↓              ↓
  케이스 생성    AI 분석 완료    8단계 라벨링    신뢰도 계산    학습데이터 준비
```

### **라벨링 생성 알고리즘**
```javascript
// 심박수 기반 자동 라벨링 예시
function analyzeVitalSigns(heartRate, baseline) {
  if (heartRate < 40) return 'severe_bradycardia';
  if (heartRate < 60) return 'bradycardia';
  if (heartRate > 150) return 'severe_tachycardia';
  if (heartRate > 100) return 'tachycardia';
  return 'normal';
}

// 응급도 분류 예시
function classifyEmergency(vitals, movement, stress) {
  if (vitals.heartRate < 35) return 'level_1_resuscitation';
  if (movement === 'fall_detected' && stress > 90) return 'level_2_emergent';
  // ... 복합 조건 분석
}
```
