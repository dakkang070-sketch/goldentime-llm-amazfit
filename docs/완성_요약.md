## 🚀 실행 방법

### 1. 초기 설정

```bash
# 자동 설정 스크립트 실행
chmod +x scripts/setup.sh
./scripts/setup.sh
```

### 2. MongoDB 실행

```bash
# 별도 터미널에서
mongod
```

### 3. Ollama 설정

```bash
# 별도 터미널에서
ollama serve

# 모델 다운로드
ollama pull llama3.1:8b

# 테스트
node scripts/test-ollama.js
```

### 4. 테스트 데이터 생성

```bash
node scripts/create-test-data.js
```

### 5. 백엔드 서버 실행

```bash
npm run dev
# 또는
npm start
```

### 6. 프론트엔드 실행

```bash
cd frontend
npm install
npm run dev
```

### 7. 통합 테스트

```bash
chmod +x scripts/integration-test.sh
./scripts/integration-test.sh
```
