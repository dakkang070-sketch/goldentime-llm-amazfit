# 국립중앙의료원 API 기반 지능형 병원 매칭 및 수용 확약 시스템

## 🏥 **개요**

**국립중앙의료원 공공 API**와 **실시간 응급실 데이터**를 활용하여 **최적의 병원을 자동으로 매칭**하고 **수용 확약까지 완료**하는 **지능형 의료 기관 연동 시스템**입니다.

### **🎯 핵심 목표**
- **🏥 실시간 병원 데이터**: 국립중앙의료원 API 실시간 연동
- **🎯 지능형 매칭**: 거리+전문성+용량+중증도 종합 분석
- **✅ 수용 확약**: 병원과의 양방향 통신으로 확실한 수용 보장
- **🔄 동적 재매칭**: 상황 변화 시 자동 대안 병원 매칭
- **📊 실시간 모니터링**: 응급실 가용 병상 실시간 추적

## 🚀 **시스템 설정 및 활용**

### **1. 환경변수 설정**
```bash
# .env 파일

NEDC_API_BASE_URL=https://apis.data.go.kr/B552657
NEDC_API_SERVICE_KEY=your_actual_service_key_here
ENABLE_HOSPITAL_MATCHING=true

# 기타 연동 시스템
ENABLE_EMERGENCY_WORKFLOW=true
ENABLE_REALTIME_BIOSIGNAL=true
ENABLE_AUTO_LEARNING=true
```

### **2. API 키 발급 및 설정**
1. **[공공데이터포털](https://www.data.go.kr)** 접속
2. **국립중앙의료원 응급의료기관 정보서비스** 신청
3. **서비스키 발급** 받아 환경변수에 설정
4. **일일 호출 한도** 확인 (보통 1,000-10,000회)

### **3. 시스템 시작**
```bash

cd backend
npm start
```
