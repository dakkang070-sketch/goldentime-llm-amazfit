# Zepp App JSON 연동 메모 (초안)

## 왜 “서버가 클라우드에서 바로 실시간 수신”이 아닐 수 있나
- `App JSON` 레퍼런스는 보통 **Zepp 앱/미니앱(워치/폰) 내부에서 호출하는 JS API**입니다.
- 따라서 실시간 데이터는 대개 다음 중 한 방식으로 서버에 도달합니다.
  - **(A) 미니앱/폰에서 우리 서버로 직접 업로드**: `fetch`/HTTP로 주기 전송(권장 MVP)
  - **(B) Zepp Cloud로 동기화 후, 우리 서버가 주기적으로 폴링**: 지연이 생길 수 있음
  - **(C) Zepp Cloud → 우리 서버 Webhook**: 지원 여부/서명 방식 확인 필요

## 우리 MVP 방향(1차)
- **미니앱(또는 폰 컴패니언) → 우리 서버 `/api/ingest/zepp`** 로 1분 단위 업로드
- 서버는 수신 즉시:
  - MongoDB 저장(`BiometricData`)
  - 규칙 기반 응급도(1~5) 산출
  - 레벨 4~5면 `EmergencyCase` 생성(입원 모드 제외)
