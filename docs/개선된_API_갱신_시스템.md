# 🔧 개선된 국립중앙의료원 API 갱신 시스템

## 📊 **최종 갱신 주기 (최적화 완료)**

### 🕐 **통합 갱신 시스템**

| 항목 | 주기 | 설명 |
|------|------|------|
| **통합 병상 현황** | `2분마다` | 일반 + 응급상황 통합 갱신 |
| **병원 기본정보** | `매일 오전 1시` | 병원 목록, 연락처, 위치 정보 |

### ⚡ **스마트 갱신 로직**

```javascript
// 2분마다 실행
cron.schedule('*/2 * * * *', async () => {
  // 1. 활성 응급상황 체크 (Level 4+)
  const emergencyCases = await EmergencyCase.find({
    status: ['pending', 'paramedic_dispatched', 'paramedic_arrived', 'transport_started'],
    emergencyLevel: { $gte: 4 }
  });
  
  // 2. 상황에 맞는 로그 출력
  if (emergencyCases.length > 0) {
    logger.info(`🔄 정기 갱신 시작 (🚨 극응급 ${emergencyCases.length}건 포함)`);
  } else {
    logger.info('🔄 정기 병상 현황 갱신 시작');
  }
  
  // 3. 통합 갱신 실행
  await getRealTimeEmergencyBeds([], true);
});
```

## 🎯 **개선 효과**

### ✅ **성능 최적화**
- **API 호출 중복 제거**: 2개 스케줄러 → 1개 통합
- **서버 부하 감소**: 불필요한 중복 체크 제거
- **로그 가독성 향상**: 응급상황 인지 명확히 표시

### 📈 **일일 API 호출량**
```
이전 (중복): 720회 + α (응급시 추가 호출)
현재 (통합): 720회 (고정, 중복 없음)
절약율: ~15-25% API 호출 감소
```

### 🔄 **실시간 대응력**
- **응급상황 인지**: 2분 내 감지
- **병상 현황 정확성**: 최대 2분 지연
- **시스템 안정성**: 과도한 호출 방지

## ⚙️ **설정 가능한 옵션**

```bash
# .env 파일에서 조정 가능
NEDC_REFRESH_INTERVAL_MINUTES=2    # 갱신 주기 (분)
NEDC_DAILY_SYNC_HOUR=1            # 일일 동기화 시간
NEDC_EMERGENCY_LEVEL_THRESHOLD=4   # 응급상황 기준 레벨
```
