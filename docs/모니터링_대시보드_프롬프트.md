# 🎨 골든타임 응급의료 시스템 모니터링 대시보드 프롬프트

## 🚀 **구글 스튜디오 프롬프트**

```
Create a modern, dark-themed real-time monitoring dashboard for an AI-powered emergency medical system called "GoldenTime". The dashboard should be professional, clean, and suitable for a 24/7 emergency control center.

## Layout Requirements:
- **Header**: System logo "GoldenTime AI Emergency System" with current time and overall system status indicator
- **Grid Layout**: 4x4 responsive grid system
- **Color Scheme**: Dark blue/black background (#0a0f1c), bright accent colors for status indicators
- **Typography**: Clean, modern sans-serif fonts, high contrast for readability

## Core Components to Include:

### 🔴 Emergency Status Panel (Top Priority)
- Large status indicator: "SYSTEM OPERATIONAL" with green/red status light
- Active emergency cases counter with pulsing animation
- Critical alerts banner (red background when active)

### 📊 Real-time System Health (Grid Section 1)
- **14 System Status Cards** arranged in a 4x4 grid:
  1. Real-time Biosignal Engine (heartbeat icon, active streams count)
  2. Auto Learning System (brain icon, training status, accuracy %)
  3. Emergency Workflow (workflow icon, active cases, SLA compliance %)
  4. Hospital Matching NEDC API (hospital icon, 414 hospitals, connection status)
  5. Medical Weighting System (scale icon, processed cases)
  6. Data Labeling (tag icon, labeled data count, accuracy)
  7. Quality Management (shield icon, system uptime %, satisfaction score)
  8. Feedback System (comment icon, feedback count, sentiment analysis)
  9. Real-time Tracking (GPS icon, tracked paramedics, ETA accuracy)
  10. Resource Management (users icon, available paramedics, capacity %)
  11. Route Optimization (route icon, calculations/min, optimization rate)
  12. Notification System (bell icon, sent notifications, success rate)
  13. Socket Communication (network icon, connected clients, latency)
  14. Cache System (database icon, hit rate %, memory usage)

### 📈 Performance Metrics (Right Panel)
- **Live Charts**:
  - API Response Times (line graph)
  - System Load (gauge chart)
  - Emergency Cases Timeline (area chart)
  - Hospital Bed Availability (bar chart by region)

### 🏥 Hospital Network Status (Bottom Left)
- **NEDC API Connection**: Green/Red indicator with "414 Hospitals Connected"
- **Real-time Updates**: "Last updated: 2 minutes ago" with countdown timer
- **Bed Availability Summary**: Available beds counter with trend arrow
- **Regional Distribution**: Mini map or list showing coverage areas

### 🤖 AI System Performance (Bottom Right)
- **Model Accuracy**: Circular progress indicator (95.3%)
- **Learning Status**: "Training Complete" or "Learning in Progress" with progress bar
- **Data Processing**: "1,247 cases processed today"
- **Auto-labeling Queue**: "23 items pending"

## Visual Design Elements:

### Status Indicators:
- **GREEN (#00ff88)**: Operational/Healthy
- **YELLOW (#ffb800)**: Warning/Attention needed  
- **RED (#ff4757)**: Critical/Error
- **BLUE (#3742fa)**: Information/Processing

### Interactive Elements:
- Hover effects on all cards showing detailed metrics
- Click to drill-down capability indicators
- Pulsing animations for active/critical items
- Smooth transitions between states

### Typography Hierarchy:
- **System Title**: Large, bold, white text
- **Section Headers**: Medium, semi-bold, light blue
- **Metrics**: Large numbers, white/green for positive values
- **Labels**: Small, gray text for descriptions
- **Status Text**: Color-coded based on system state

### Iconography:
- Use medical and technology icons (heartbeat, hospital, CPU, network, etc.)
- Consistent icon style (outline or filled)
- Appropriate sizing for each component

### Real-time Elements:
- Live updating counters with smooth number transitions
- Blinking/pulsing indicators for active alerts
- Progress bars for ongoing operations
- Timestamp displays with "last updated" information

## Specific Styling Notes:
- Rounded corners on all cards (8px border-radius)
- Subtle shadows and borders for depth
- Grid spacing with consistent margins
- Responsive design that works on large displays
- High contrast ratios for accessibility
- Professional emergency control room aesthetic

## Sample Text Labels:
- "Real-time Biosignal Analysis: 12 Active Streams"
- "NEDC Hospital Network: 414 Connected, 2,847 Beds Available"  
- "Emergency Workflow: 3 Active Cases, 98.5% SLA Compliance"
- "AI Learning System: Model Training Complete, 96.2% Accuracy"
- "System Uptime: 99.97% (247 days)"
- "Response Time: <200ms average"

Create this as a comprehensive, professional monitoring dashboard that would be suitable for a real emergency medical control center, with attention to both functionality and visual appeal.
```
