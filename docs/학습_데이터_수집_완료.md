## 데이터 구성

각 샘플은 다음 형식을 따릅니다:

```json
{
  "instruction": "응급구조사가 참고할 상황 요약을 작성하세요. 의료적 진단은 하지 마세요.",
  "input": "기초선 심박수: 72 bpm, 현재 심박수: 45 bpm, 스트레스: 85, 움직임: 정상, 위치: 서울시 강남구",
  "output": "심박수가 기초선 대비 현저히 낮아진 상황입니다..."
}
```

## 다음 단계

### 1. 파인튜닝 모델 생성
```bash
./scripts/fine-tune-model.sh
```

### 2. 실제 운영 데이터 수집 (선택사항)
MongoDB가 실행 중이고 실제 응급 케이스 데이터가 있는 경우:

```bash
# 의존성 설치
npm install

# MongoDB 실행 확인 후
node scripts/prepare-fine-tuning-data.js
```

이 스크립트는:
- EmergencyCase에서 LLM 분석 결과가 있는 케이스 수집
- BiometricData에서 분석된 생체 데이터 수집
- 기본 샘플 데이터와 병합
- `fine-tuning-dataset-combined.json` 파일 업데이트

## 참고사항

- 현재는 기본 샘플 데이터셋만 사용 가능합니다
- 실제 운영 데이터 수집을 위해서는 MongoDB 실행 및 의존성 설치가 필요합니다
- 학습 데이터는 자동으로 수집되도록 시스템에 통합되어 있습니다 (응급 상황 발생 시)
