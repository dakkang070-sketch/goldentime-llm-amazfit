# 파인튜닝 모델 생성 가이드

## 사전 요구사항

1. **Ollama 설치**
   ```bash
   # macOS
   brew install ollama
   
   # 또는 공식 사이트에서 다운로드
   # https://ollama.ai
   ```

2. **Ollama 서버 실행**
   ```bash
   # 터미널에서 실행 (별도 창)
   ollama serve
   
   # 또는 백그라운드 실행
   ollama serve > /dev/null 2>&1 &
   ```

3. **기본 모델 다운로드**
   ```bash
   ollama pull llama3.1:8b
   ```

## 모델 생성 방법

### 방법 1: 스크립트 사용 (권장)

```bash
cd /path/to/goldentime-llm
chmod +x scripts/fine-tune-model.sh
./scripts/fine-tune-model.sh
```

### 방법 2: 수동 생성

```bash
cd /path/to/goldentime-llm/backend/data
ollama create goldentime-emergency:latest -f Modelfile
```

## 생성된 모델 확인

```bash
ollama list
```

다음과 같은 출력이 보여야 합니다:
```
NAME                        SIZE
llama3.1:8b                 4.7 GB
goldentime-emergency:latest  4.7 GB
```

## 모델 테스트

```bash
ollama run goldentime-emergency:latest "기초선 심박수: 70 bpm, 현재 심박수: 45 bpm, 스트레스: 85"
```

예상 출력:
```
심박수가 기초선 대비 현저히 낮아진 상황입니다. 현재 심박수 45 bpm은 정상 범위를 크게 벗어났습니다...
```

## 환경변수 설정

`.env` 파일에 다음 설정 추가:

```env
# 파인튜닝된 모델 사용
USE_FINETUNED_MODEL=true
OLLAMA_FINETUNED_MODEL=goldentime-emergency:latest
ENABLE_OLLAMA=true
```

## 문제 해결

### Ollama 서버 연결 실패
- `ollama serve` 명령으로 서버가 실행 중인지 확인
- 포트 11434가 사용 가능한지 확인

### 모델 다운로드 실패
- 인터넷 연결 확인
- `ollama pull llama3.1:8b` 수동 실행

### 모델 생성 실패
- Modelfile 경로 확인: `backend/data/Modelfile`
- Ollama 서버 로그 확인
