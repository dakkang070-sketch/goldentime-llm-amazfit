# 골든타임 LLM 보안 가이드

## 🔒 보안 기능

### 1. 인증 및 권한

- **JWT 토큰 인증**: 모든 API 엔드포인트는 JWT 토큰 기반 인증 사용
- **역할 기반 접근 제어 (RBAC)**: user, paramedic, controller, admin 역할 구분
- **비밀번호 해싱**: bcrypt를 사용한 안전한 비밀번호 저장

### 2. Rate Limiting

- **일반 API**: 15분당 100회 요청 제한
- **인증 API**: 15분당 5회 시도 제한 (무차별 대입 공격 방지)
- **생체 데이터 업로드**: 1분당 10회 제한
- **통계 API**: 1분당 30회 제한

### 3. 입력 검증

- **데이터 검증**: validator 미들웨어를 통한 입력값 검증
- **SQL Injection 방지**: Mongoose를 통한 쿼리 파라미터화
- **XSS 방지**: 입력값 이스케이프 처리

### 4. 보안 헤더

- **CORS**: 허용된 도메인만 접근 가능
- **환경변수 보안**: 민감한 정보는 환경변수로 관리

## 🔐 환경변수 보안

### 필수 환경변수

```env
# 강력한 비밀키 사용 (최소 32자)
JWT_SECRET=your-very-long-and-random-secret-key-here

# MongoDB 연결 (인증 정보 포함)
MONGODB_URI=mongodb://username:password@host:port/database

# 프로덕션에서는 HTTPS 사용
FRONTEND_URL=https://yourdomain.com
```

### 보안 권장사항

1. **비밀키 생성**: 
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

2. **환경변수 파일 권한**:
   ```bash
   chmod 600 .env
   ```

3. **Git에 커밋하지 않기**: `.env` 파일은 절대 커밋하지 않음

## 📋 보안 모니터링

### 모니터링 항목

- 실패한 로그인 시도 횟수
- 비정상적인 API 호출 패턴
- Rate Limit 초과 시도
- 데이터베이스 쿼리 오류
- 메모리/CPU 사용량 급증

### 알림 설정

- 실패한 로그인 시도 10회 이상
- Rate Limit 초과 빈번 발생
- 서버 오류 급증
- 데이터베이스 연결 실패
