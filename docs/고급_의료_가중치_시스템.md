# 🧮 고급 의료 가중치 시스템

골든타임 LLM의 고급 의료 가중치 시스템은 실제 의료 현장의 복잡성을 반영한 정교한 위험도 계산 엔진입니다.

## 📊 가중치 시스템 비교

### **❌ 기존 단순 시스템**
```javascript
// 고정된 단순 임계값
if (heartRate < 40) level = 5;        // 모든 환자 동일 기준
if (heartRate > 160) level = 4;       // 개인차 무시
if (stress > 90) level = 3;           // 단일 지표만 고려
```

**문제점:**
- 모든 환자에게 동일한 기준 적용
- 나이, 성별, 기저질환 미고려  
- 시간대, 지역, 환경 요소 무시
- 지표 간 상호작용 미반영

### **✅ 새로운 고급 시스템**
```javascript
// 다중 요소 복합 가중치 계산
riskScore = (생체신호 40점) + (개인요소 30점) + (상황요소 20점) + (시간요소 10점)
최종점수 = 기본점수 × 연령가중치 × 기저질환가중치 × 시간가중치
```

**장점:**
- 개인별 맞춤형 위험도 계산
- 의료 가이드라인 기반 가중치
- 실시간 상황 반영
- 신뢰도 함께 제공

## 🎯 가중치 테이블 상세

### **1. 연령별 가중치**
```javascript
ageWeights: {
  '0-17': 1.3,    // 소아: 30% 증가 (생리적 불안정)
  '18-30': 1.0,   // 청년: 기준값
  '31-50': 1.1,   // 중년: 10% 증가
  '51-65': 1.3,   // 장년: 30% 증가
  '66-80': 1.6,   // 고령: 60% 증가
  '80+': 2.0      // 초고령: 100% 증가 (매우 높은 위험)
}
```

**의학적 근거:**
- 소아: 생리적 예비능력 부족, 빠른 상태 악화
- 고령자: 다중 기저질환, 회복력 저하, 합병증 위험

### **2. 성별별 질환 가중치**
```javascript
genderWeights: {
  cardiac: { male: 1.2, female: 1.0 },      // 남성 심장질환 20% 높음
  respiratory: { male: 1.0, female: 1.1 },  // 여성 호흡기 질환 10% 높음
  trauma: { male: 1.1, female: 0.9 },       // 남성 외상 위험 10% 높음
  neurological: { male: 1.0, female: 1.0 }  // 신경과적 질환 동일
}
```

**의학적 근거:**
- 남성: 관상동맥질환 조기 발병, 외상 빈도 높음
- 여성: 자가면역질환, 호르몬 영향 호흡기 질환

### **3. 기저질환 가중치**
```javascript
comorbidityWeights: {
  diabetes: 1.4,           // 당뇨: 40% 위험 증가
  hypertension: 1.3,       // 고혈압: 30% 증가
  heart_disease: 1.8,      // 심장병: 80% 증가 (가장 높음)
  copd: 1.6,              // COPD: 60% 증가
  kidney_disease: 1.5,     // 신장병: 50% 증가
  cancer: 2.0,            // 암: 100% 증가 (면역저하)
  immunocompromised: 1.7   // 면역저하: 70% 증가
}
```

**의학적 근거:**
- 당뇨: 혈관 합병증, 감염 위험, 상처 치유 지연
- 심장병: 급성 악화 시 생명 위험, 응급처치 필요
- 암/면역저하: 감염 위험, 다양한 합병증

### **4. 시간대별 가중치**
```javascript
timeWeights: {
  'dawn': 1.2,      // 새벽 (00-06): 20% 증가
  'morning': 1.0,   // 아침 (06-12): 기준
  'afternoon': 0.9, // 오후 (12-18): 10% 감소
  'evening': 1.1,   // 저녁 (18-24): 10% 증가
  'weekend': 1.3,   // 주말: 30% 증가
  'holiday': 1.4    // 공휴일: 40% 증가
}
```

**의학적 근거:**
- 새벽: 의료진 최소 인력, 교통 접근성 제한
- 주말/공휴일: 응급실 집중, 전문의 부족

### **5. 지역별 가중치**
```javascript
locationWeights: {
  urban: 1.0,       // 도시: 기준 (의료 접근성 양호)
  suburban: 1.2,    // 교외: 20% 증가
  rural: 1.5,       // 시골: 50% 증가 (병원까지 거리)
  remote: 2.0       // 오지: 100% 증가 (헬기 이송 필요)
}
```

## 🧮 위험도 계산 예시

### **예시 1: 80세 남성, 심장병 병력**
```javascript
// 기본 생체신호: 심박수 45 bpm
vitalSignsScore = 12점  // 서맥

// 개인요소: 80세 + 남성 + 심장병
personalScore = 10점 (고령) + 5점 (남성 심장병) = 15점

// 상황요소: 새벽 2시
contextualScore = 4점

// 시간요소: 없음
temporalScore = 0점

기본점수 = 12 + 15 + 4 + 0 = 31점
가중치 적용 = 31 × 2.0 (초고령) × 1.8 (심장병) × 1.2 (새벽) = 134점
최종점수 = 100점 (최대값으로 제한)

결과: 응급도 5단계 (즉시 대응 필요)
```

### **예시 2: 25세 여성, 기저질환 없음**
```javascript
// 기본 생체신호: 심박수 140 bpm (운동 후)
vitalSignsScore = 8점  // 빈맥

// 개인요소: 25세 + 여성 + 기저질환 없음
personalScore = 0점

// 상황요소: 오후 3시
contextualScore = 0점

// 시간요소: 없음
temporalScore = 0점

기본점수 = 8 + 0 + 0 + 0 = 8점
가중치 적용 = 8 × 1.0 (청년) × 1.0 (기저질환 없음) × 0.9 (오후) = 7.2점

결과: 응급도 1단계 (정상 모니터링)
```

## 📊 품질 관리

### **신뢰도 계산**
```javascript
confidence = (데이터완성도 × 0.4) + (기초선데이터 × 0.3) + (의료이력 × 0.3)

// 예시
데이터완성도: 90% (심박수, 산소, 스트레스, 움직임 모두 있음)
기초선데이터: 100% (개인 평상시 데이터 있음)
의료이력: 80% (기저질환 일부 정보 있음)

신뢰도 = (0.9 × 0.4) + (1.0 × 0.3) + (0.8 × 0.3) = 0.9 (90%)
```

### **실시간 검증**
```javascript
// 의료진 피드백으로 가중치 자동 조정
```
