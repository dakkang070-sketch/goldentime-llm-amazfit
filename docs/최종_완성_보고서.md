## 🚀 실행 방법

### 1. 초기 설정

```bash
./scripts/setup.sh
```

### 2. 환경변수 설정

```bash
cp config/env.example .env
# .env 파일 편집
```

### 3. MongoDB 실행

```bash
mongod
```

### 4. Ollama 설정

```bash
ollama serve
ollama pull llama3.1:8b
node scripts/test-ollama.js
```

### 5. 테스트 데이터 생성

```bash
node scripts/create-test-data.js
```

### 6. 백엔드 서버 실행

```bash
npm run dev
```

### 7. 프론트엔드 실행

```bash
cd frontend
npm install
npm run dev
```

### 8. 통합 테스트

```bash
./scripts/integration-test.sh
```
